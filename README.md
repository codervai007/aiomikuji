# AIおみくじ（AI Omikuji Booth Demo）

IT Connect Fes 2026 のブース体験「AIおみくじ」のデモ画面です。

## できること

- 性別・年齢（任意）・部署を選び、100個の引き出し（一〜百）から1つ選んで「おみくじを引く」
- 運勢と当たり（マグカップ）はプログラムの乱数で抽選（AIは抽選しない）
- 指示文（プロンプト）を組み立て、生成AIがおみくじの文章を作成
- 文字数・不適切な表現をチェックしてから「印刷」（表：おみくじ／裏：指示文とAIのコツ）
- 「裏側モニター」で、入力 → 抽選 → 指示文 → AI → 確認の流れを表示
- 「お仕事でAIを使っていますか？」のアンケートを部署別に集計、CSVでコピー

## スタッフ設定

ページ下部の「スタッフ設定」で変更できます（設定はブラウザに保存）。

- 想定来場者・マグカップ数（当たり確率 ＝ 残りのマグカップ ÷ 残りの想定来場者）
- 裏面に載せるAIのコツ（15個から選択、ランダム／固定）
- 部署リスト

## 使い方

`index.html` をブラウザで開くだけで動きます。GitHub Pages でも公開できます。

> 生成AIへの接続は Claude のアーティファクト上でのみ動作します。
> それ以外の環境では、用意したテンプレート文でおみくじを作ります。
> 本番では、社内で承認されたAIサービスにサーバー経由で接続してください。
